# QA Automation Portfolio

Este repositório reúne projetos de automação de testes desenvolvidos ao longo da minha jornada de aprendizado, incluindo estudos práticos, treinamentos e projetos pessoais.

O objetivo é demonstrar minhas habilidades em Quality Assurance, aplicando diferentes ferramentas, linguagens, frameworks e boas práticas de automação em cenários reais e simulados.

## 🔧 Tecnologias e Ferramentas

* Testes Web: Cypress, Playwright, Selenium, Robot Framework
* Testes de API: Postman, Rest Assured
* Testes Mobile: Appium, Robot Framework
* Testes Não Funcionais: JMeter, k6
* Linguagens: Java, JavaScript, TypeScript, Python, C#

## 🧪 Tipos de Testes

* Testes End-to-End (E2E)
* Testes de API
* Testes Web
* Testes Mobile
* Testes de Performance (não funcionais)
* Testes Funcionais

## 📚 Projetos Incluídos

Entre os projetos disponíveis neste portfólio, destacam-se:

* Automação Web e API com Cypress
* Automação Web e API com Playwright
* Automação Web com Selenium em C#
* Automação de APIs com Rest Assured (Java)
* Automação Mobile com Appium e Robot Framework
* Automação Web e API com Robot Framework
* Testes de Performance com JMeter
* Testes de Performance com k6

## 🏗️ Frameworks e Padrões Aplicados

* Page Object Model (POM)
* Boas práticas de automação de testes
* Estruturação de projetos de automação
* Automação de APIs REST
* Validações funcionais e de integração

## 🎯 Objetivo do Repositório

Este portfólio tem como foco:

* Praticar e evoluir minhas habilidades em automação de testes
* Explorar diferentes ferramentas, frameworks e abordagens de QA
* Consolidar conhecimentos adquiridos em cursos e experiências práticas
* Demonstrar organização de código, estrutura de testes e boas práticas de desenvolvimento

## 📁 Estrutura do Repositório

Os projetos estão organizados em arquivos `.zip` devido ao tamanho e à diversidade de tecnologias utilizadas.

Cada arquivo contém um projeto completo de automação, incluindo:

* Estrutura de testes
* Configuração do ambiente
* Scripts de automação
* Exemplos práticos de execução

## 📌 Observações

Os projetos aqui presentes representam diferentes cenários de aprendizado e evolução técnica, podendo variar em complexidade, arquitetura e abordagem conforme o contexto de estudo. E estão no formato ".rar" contendo todo conteúdo de pastas e arquivos.
